— I —

核心功能

features of the journal
No. 01
喜
情绪感知
自动识别用户输入中的情绪状态，分析情绪强度和关键词，让日记更有情感深度。
No. 02
记
长期记忆
基于 ChromaDB 向量数据库和 BGE 中文嵌入模型，智能检索和保存重要记忆，跨对话连贯。
No. 03
书
日记生成
融合情绪分析和历史记忆，自动生成温暖、个性化的日记文本，支持 Markdown 导出。
No. 04
流
实时进度
SSE 流式响应，实时显示每个智能体的处理状态，告别等待焦虑。
No. 05
册
日记管理
自动保存每篇日记，支持历史浏览、详情查看、关键词搜索、单篇/批量导出。
No. 06
雅
文学界面
纸质信笺美学，朱砂墨色配色，霞鹜文楷字体，响应式布局，沉浸式书写体验。

— III —

快速开始

how to begin
# 1. 克隆项目
git clone https://github.com/w020316/geren-riji.git
cd geren-riji

# 2. 安装依赖
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 填入 Agnes AI API Key

# 4. 启动服务
python main.py

# 浏览器访问 http://localhost:8000
