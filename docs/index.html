核心功能

🎭
情绪感知
自动识别用户输入中的情绪状态，分析情绪强度和关键词，让日记更有情感深度。
🧠
长期记忆
基于 ChromaDB 向量数据库和 BGE 中文嵌入模型，智能检索和保存重要记忆，跨对话连贯。
📝
日记生成
融合情绪分析和历史记忆，自动生成温暖、个性化的日记文本，支持 Markdown 导出。
✨
实时进度
SSE 流式响应，实时显示每个智能体的处理状态（working → done），告别等待焦虑。
📔
日记管理
自动保存每篇日记，支持历史浏览、详情查看、单篇/批量导出 Markdown 文件。
🌙
精美界面
暗色主题设计，渐变背景动效，响应式布局，移动端完美适配，沉浸式体验。

快速开始

# 克隆项目
git clone https://github.com/w020316/geren-riji.git
cd geren-riji

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
cp .env.example .env
# 编辑 .env 填入 DeepSeek API Key

# 启动服务
python main.py

# 浏览器访问 http://localhost:8000
